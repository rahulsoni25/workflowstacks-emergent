# Kokonut UI — free component slugs

Snapshot of the 116 free components in `registry/registry-components.ts`
(kokonut-labs/kokonutui, read 2026-11-12), grouped by docs category.
Install any of them with `npx shadcn@latest add @kokonutui/<slug>`.

The registry changes over time. Before you tell the user a component
exists, confirm it in the live index at https://kokonutui.com/llms.txt or
with the shadcn MCP server.
